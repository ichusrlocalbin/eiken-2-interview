# 英検®2級 面接練習アプリ

英検®2級の二次試験（面接）を、本番に近い流れで練習するための iOS アプリです。面接官の質問を音声で聞いて英語で答えると、オンデバイスの AI が採点し、改善点を日本語でフィードバックします。

> 英検®は、公益財団法人 日本英語検定協会の登録商標です。
> このアプリは、公益財団法人 日本英語検定協会の承認や推奨、その他の検討を受けたものではありません。

## できること

- **本番モード**: あいさつ → 黙読20秒 → 音読 → No.1〜No.4 を、本番と同じ流れで練習（約7分）
- **苦手復習**: 得点率が60%未満だった項目だけを、もう一度練習
- **特訓モード**: 音読・No.1・No.2・No.3/4 を1つずつ、ヒント付きで練習
- **採点とフィードバック**: 33点満点で採点し、良かった点・改善点・文法を直した英文・模範解答を表示
- **聞き返し**: 聞き取れなかったときに “Pardon?” などと言うと、面接官が質問を言い直す（3回以上で減点）
- **履歴とグラフ**: 点数の推移、項目別の得点率、よくあるミス
- **問題の追加**: 手入力（イラストは写真から）や JSON の取り込みで、問題を増やせる

音声認識（SpeechAnalyzer）と採点（Foundation Models）はすべて端末の中で動き、録音や回答が外部に送られることはありません。

## 動作環境

- iOS 26 以降
- Apple Intelligence に対応した iPhone（設定で Apple Intelligence をオンにしておく）
- Xcode 26 以降（iOS 27 の端末に入れる場合は Xcode 27）

シミュレータでは音声認識と AI 採点が動かないため、動作の確認には実機が必要です。

## ビルド

1. `Config/Local.xcconfig` を作り、自分の開発チームIDを書く（このファイルは git の管理外）

   ```
   DEVELOPMENT_TEAM = XXXXXXXXXX
   ```

2. 必要に応じて `Eiken2Interview.xcodeproj` のバンドルID（`PRODUCT_BUNDLE_IDENTIFIER`）を自分のものに変える
3. `Eiken2Interview.xcodeproj` を Xcode で開き、実機を選んで実行する

## 問題データについて

付属の問題15セット（パッセージ・質問・模範解答・イラスト）は、すべてこのアプリのために作ったオリジナルです。英検®の過去問や問題集の問題は含んでいません。イラストは画像生成 AI で作成しました。

問題の形式は `Eiken2Interview/Problems/set-*.json` を、イラストの作り方は `prompts/illustrations.md` を参照してください。仕様の詳細は [SPEC.md](SPEC.md) にあります。
