# イラスト生成プロンプト（ChatGPT 用）

## 使い方

1. 下の「共通の指示」と、各セットのプロンプトを**まとめて**ChatGPT に貼り付ける
2. 画像ができたら、指定のファイル名（例: `set-001-illust.png`）で `assets-inbox/` に保存する
3. Claude に「イラストを置いた」と伝える → コマの内容が問題と合っているかチェックし、OK ならアプリに組み込みます

うまくいかないとき: 「3コマが横一列に並んでいない」「人物の見た目がコマごとに違う」などは、そのまま ChatGPT に「〜を直して」と伝えれば修正できます。

---

## 共通の指示（毎回いっしょに貼る）

```
Create a single landscape image (3:2) containing a 3-panel comic strip, with the three panels arranged side by side from left to right, each separated by a thin black border.
Style: simple, clean black-and-white line drawing with light gray shading, like an illustration on an English proficiency test picture card. Plain backgrounds, no color.
Characters must look the same in all three panels (same hairstyle, clothes, and age).
Do NOT put any text, letters, numbers, or captions anywhere in the image, EXCEPT inside the speech bubble described below, which must contain exactly the given English sentence.
Thought bubbles contain only a small picture, never words.
```
